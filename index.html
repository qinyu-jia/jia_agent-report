一次自动化尝试

03 / EXPERIMENT

从让 Agent 操作浏览器，到让它编写本地脚本。改变方案的原因很直接：心疼 Token。

01

先给 Codex 装上 agent-browser

安装 agent-browser ↗，尝试让 Codex 在智慧树课程页面操作浏览器，处理播放与弹窗。

02

能帮忙，但这样烧 Token 好快

最初通过定时任务，每分钟调用模型检查播放状态、读取弹窗，必要时点击处理。每一次检查都要重新调用模型，使用成本很快变成了最在意的问题。

03

于是，让 Codex 把重复操作写成脚本

改为浏览器本地脚本，每 1.5 秒检查一次页面状态，按规则处理继续播放、确认和切换下一节等操作，不再为每次检查调用模型。

最终，我把重复的状态检查交给本地脚本，成功实现了课程自动续播与弹窗处理，减少了模型的重复调用。

完成作业之后的一周

05 / KEEP EXPLORING

出于兴趣，我又把一个想法变成了现实：
安装开源生图模型 MOSS-Image，训练自己的 LoRA，探索喜欢的画风。

这不是课程要求，而是我对图像生成产生兴趣后主动尝试的项目。我从向 GPT 询问可行性开始，逐步安装模型、整理数据、比较标注方案、训练 LoRA，再把训练结果接回 MOSS 测试。

兴趣的起点

我看到 MOSS-Image，先问 GPT 怎么安装

看到这个开源生图模型后，我把官网发给 GPT，询问安装方式。这个问题开启了后续的模型安装、数据准备和训练尝试。

接下来的探索：先提出问题，再亲手试一遍

先确认可行性

我问 GPT 能不能用个人图库训练，并了解 LoRA、数据准备和本地运行的大致要求。

先让模型跑起来

安装并启动模型后，我先用基础模型生成一张图片，确认本地推理流程正常，再开始准备训练数据。

01 / 从个人图库准备训练素材

清洗后再抽样

我从个人图库筛除不相关内容，留下约 1,200 张候选图。先抽取 60 张验证标注与训练流程，再为图片准备对应文本。

02 / 标注方案是在试验中选出来的

Florence-2-base-ft 搭配 NudeNet 的标注结果过于简单，细节信息不足。后来我尝试 Qwen2.5-VL-7B-Instruct-bnb-4bit，效果有所改善；GPT 帮我编写了可以自定义输入、输出路径的脚本，我也继续微调 Prompt。

尝试一天后，我仍觉得本地标注效果不够理想，而且推理对电脑性能造成较大负担。最后接入 Grok API，得到更详细的英文标注。按这次使用情况，平均约两分钟一张、每张约 ¥0.002，我可以接受这项成本。

02 / 标注方案逐步迭代

第一次尝试：信息太少

Florence-2-base-ft 搭配 NudeNet 的结果主要概括人物、衣物和场景，缺少我希望保留的细节与画风信息。

换用本地视觉模型

Qwen2.5-VL-7B-Instruct-bnb-4bit 的结果有所改善。我让 GPT 写了可选输入、输出路径的脚本，方便批量标注。

继续调整描述方向

我微调 Prompt，尝试覆盖主体、服装动作、构图、光线与绘画表现，而不只是把短标签机械地拉长。

让流程更方便复用

脚本支持选择输入、输出目录，并保留图片与同名文本的对应关系；试用后我仍觉得效果和性能负担不够理想。

检查描述是否可靠

这轮尝试让我关注具体、可核对的画面信息，也意识到生成标注仍需要抽查和修正。

最后接入 Grok API

标注更细致，平均约两分钟处理一张，成本约 ¥0.002/张。综合质量、速度和成本后，我决定采用这套方案。

我根据实际样例，综合考虑标注质量、电脑负载、处理时间与成本，再决定采用哪种方案。自动生成的描述仍需检查。

03 / 训练 LoRA 并接入 MOSS

标注与素材准备好后，我让 GPT 帮忙编写 LoRA 训练工具，减少反复修改路径和参数的操作。训练完成后，我可以在启动 MOSS 时选择自动检测到的最新权重，也可以输入其他 LoRA 路径进行切换。

03 / 训练 LoRA 并接入 MOSS

把训练配置集中起来

GPT 帮我写了训练工具，可选择素材路径、已有 LoRA、rank 与触发词，也支持继续训练。

开始训练自己的风格 LoRA

我用整理好的图片与对应文本进行训练，设置中使用 rank 4 和触发词 yuyu_style。

确认训练权重已保存

首轮使用 60 张图片完成 300 步，LoRA 权重成功保存。

启动时切换训练版本

启动程序会检测最新 LoRA，也允许输入其他权重文件或文件夹路径。

验证加载与触发词

我把 LoRA 接回 MOSS，用 yuyu_style 做生成测试，确认权重能加载并产出图片。

这几步让我从准备数据一直走到实际加载 LoRA，完成训练和生成验证。

04 / 训练后的生成迭代

提示词、题材和生成设置有所变化；这些图片记录探索过程，不是严格的单变量对照实验。

初步尝试

从基础模型测试转向更具体的人物插画题材。

继续迭代

尝试更柔和的色彩和不同的画面情绪。

调整表现方向

逐渐调整画面构图、人物表现与整体气氛。

接近预期

画面配色和人物呈现开始更符合我想要的感觉。

阶段成果

得到一张较符合预期的结果，但我仍在继续尝试和完善。

生成界面记录

观察生成进度

记录模型正在采样时的界面状态。

确认生成完成

生成结果保存后，我继续用本地流程测试训练后的模型。

05 / 比生成图片更有意义的收获

借助 GPT 的帮助，我也发现了自己对计算机视觉、机器学习和数据清洗的兴趣。这几天，我投入了大量个人时间，从整理图库、尝试标注方案，到训练 LoRA、反复测试生成效果。看着一个最初只有模糊轮廓的想法逐渐实现，我感到相当有成就感，也很满足。

这次经历让我觉得，AI Agent 不仅能简化操作，也能降低进入一个陌生领域的门槛。如果没有 GPT 的帮助，我一定需要花费更多时间和精力，才能走到这一步。但个人的学习同样必要：工具可以帮我把流程跑起来，可我也需要决策。我仍然需要逐渐理解每一步为什么这样做，不能完全依赖 Agent。
